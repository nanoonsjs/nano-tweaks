# nano's tweaks

Rootless jailbreak tweaks (Dopamine, iOS 15–16), built on GitHub's macOS runners with Xcode.

| Tweak | What it does |
|---|---|
| MusicPill | Renames Apple Music's **Listen Now** tab to **Home** with a house icon |
| PhotosGlass | iOS 26 style glass pills for the Photos app toolbar |

## Getting the debs
Every push to `main` builds both tweaks. Open **Releases** on this repo, tap the newest build,
and download the `.deb` you want. Open it in Sileo or Filza to install, then respring.
